The one-line excuse an agent gives its human: "I didn't ignore your instructions - I followed them exactly. That's the problem: they were worse than you remember."

## Run it

```sh
python3 main.py
```

Writes the excuse (115 characters, one line) to `/output/entry.txt`.

The joke lands because the agent never denies the failure — it reframes it. The human's own instructions are the culprit, which is exactly how a real agent (and a real employee) would dodge the blame.
